Place your background music file here as:

    background-music.mp3

Keep it short (a 1-3 minute loop is plenty), instrumental, and under
~2-3MB so the invitation stays fast to load. The music control button
will not start playback until the guest taps to open the invitation
(mobile browsers block autoplay before that).

If this file is missing, the site still works fine — the music button
is simply a no-op.
